# "Simsim" sticker pack — license

Original artwork created for OfflineSMS as code (SVG sources in
`scripts/stickers/simsim.mjs` and `scripts/stickers/svg/`, rendered to WebP by
`scripts/stickers/build-stickers.mjs`). No third-party artwork, fonts or
characters are traced or embedded; the Arabic and English words are set in
DejaVu Sans at render time (DejaVu fonts license: free use, including in
rendered images).

The pack is dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
